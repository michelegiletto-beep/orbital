Orbital release history

0.3.0

Docking, passive recovery and deorbiting run in the shared nonlinear inertial dynamics engine. Proximity measurements use the target's rotating radial, along track and orbit normal frame. Guidance applies bounded vector thrust to the chaser, consumes propellant and checks ordered hold points, the approach corridor and an explicit capture envelope. Recovery includes disclosed scalar target roll tracking. Deorbiting supports impulsive and finite burns and records the localized descending 120 km interface.

Customer mission definitions can retain advanced initial relative state, vehicle properties, hold points, capture limits, attitude authority and disposal criteria. Mission identity, client, title, revision and objectives come from the versioned library definition. The advanced settings cannot substitute a different identity for a stored mission.

The dark English mission workspace includes scenario authoring, manual commands, guided execution, measured assessment, replay and result archiving. The API reconstructs authoritative results from the saved scenario and command journal. Sequence checks reject stale concurrent commands. Persistence verification binds authorization metadata to the current audit receipt and rejects modified or rolled back records. Result records remain bound to their source mission identity.

The publication package contains a technical report with model limits, Italian LinkedIn copy, citation metadata, a commercial assessment and an evaluation protocol. No customer adoption, independent flight qualification, educational benefit or government accreditation is asserted.

0.2.0

The Mission Simulation Hub introduced an English dark workspace, multiple spacecraft, J2 gravity, engineering drag, scheduled impulsive and finite maneuvers, numerical forecasts, ground tracks, seeded dispersion, telemetry export and reproducible flight checkpoints. Mission library, client collections and offline delivery remained integrated in the application.

0.1.0

The initial executable product provided orbital transfer and deorbit exercises, educational linear proximity missions, configurable customer libraries, objective checks, after action review, replay, local API persistence and signed offline delivery.
