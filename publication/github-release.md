Orbital Mission Simulation Hub

Version 0.3.0

This release brings docking, passive recovery and deorbiting into the advanced mission workspace. Scenarios are editable per customer and retain the parameters and assessment criteria used for each run.

Docking and recovery use two numerically propagated spacecraft, measured relative state, ordered approach points and explicit capture limits. Finite vector thrust consumes propellant. Recovery adds the disclosed target rotation and control authority model. Deorbiting supports impulsive or finite maneuvers and checks the descending atmospheric interface. These models support training and procedure exploration. They do not model contact mechanics, full rigid body dynamics, atmospheric heating or ground impact.

The dark English application includes mission authoring, flight control, replay, assessment records, server checkpoints and offline delivery. The technical report explains the model and validation scope. The release verification record identifies the exact tested revision and environment. Checksums and signatures support package integrity; trust in the public key must be established independently.
